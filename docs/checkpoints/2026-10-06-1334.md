## Decisions
- Замок двухуровневый (глобальный во всех папках, локальный только в своей, приоритет глобального); ключ `sync_rev` плоская строка, неприметное имя, имя/слова lock/password не попадают в ошибки, логи, события; тексты отказов обращены к агентам. Канонический путь глобального замка берётся без env-переопределений, но не мешает записи в изолированный временный глобальный файл. Принято как ограничение: если ОС не назвала каноническую папку, этот источник пропускается (fail-open, редкое сочетание).
- Хеш блока `models` (`cache_rev`): пересчёт только при записи, затрагивающей `models`; служебные записи его не трогают; нет ключа — принято, но при наличии любого замка это нарушение; проверка один раз при старте; команды выполнения прерываются, команды управления настройками — нет (иначе нечем чинить).
- Heartbeat: один файл на (папка запуска, корневая сессия, pid) со ВСЕМИ моделями сессии, каталог `heartbeat/` рядом с глобальным rush.json (+ RUSH_HEARTBEAT_DIR), без парсинга `$$` (явный RootSessionID), запись temp+rename, без очередей на горячем пути.
- Агентам rush больше не поручать прогон мутантов и полных пакетов: тяжёлая очередь делит время агента; приёмку (мутанты, полные пакеты, ревью `@ox` + `--role reviewer`) делаю я.
- CHANGELOG ведётся на английском; `SilenceUsage` на корне оставлен (usage после ошибки подсказывал бы флаг `--password`).
