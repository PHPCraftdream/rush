## Decisions
- Структурный рефакторинг вместо новых раундов ревью «до нуля P3»: находки плато (12–16 за раунд, около половины — следствия фиксов). Действует Review Stop Rule; P2/P3-фикс не вводит нового изменяемого состояния.
- Классификатор активности (по @oxx):
  - порядок `in_turn > delegating > between_turns > crashed > ended > idle`;
  - живая работа важнее мёртвого PID;
  - `delegating` ⇔ есть живые делегации;
  - `ended` — только по `ended_reason`;
  - долг держит сессию живой только при живом драйвере.
- Арбитр: гейт паузы применяется ко всем сессиям, включая ребёнка с идущей делегацией (исправление порядка §9.1); при расхождении образцом считается код. R-ARB-2 не вливается, пока не разобраны расхождения тени.
- Стоимость (по @oxx):
  - `cost_self` только растёт; сброс пишет `cost_base`;
  - рёбра дерева — только делегации;
  - миграция M1 только аддитивная (`cost` и `parent_cost_accounted` — путь отката);
  - формула backfill по @oxx; активность поддерева — запросом, без записи `updated_at` родителя.
- A14: окно 3 с для `bash`/`run_command`, inline-доставка через ack gate одной транзакцией. Отвергнуто: сплавлять терминальный переход с ack; sync по эвристике read-only.
- Фоновые shell: сначала инвентаризация. Предпочтение — продолжать строку обёрнутого вызова (без нового kind и rebuild); код-мост гибридного периода не нужен.
