## Decisions

- R4-1/R4-2/R4-3: fix by restoring the EXISTING R3-4 per-call arming mechanism (persist+recompile the spec, rebind via `LogicalCallID`) rather than patching the new F2 baseline's symptoms one at a time — closes both P0 findings by construction. Kept the old baseline as a demoted legacy-row-only fallback rather than deleting it outright, since removal would silently change behavior for durable rows persisted before the fix shipped.
- Sequenced #842 (redesign) before #843 (dead-reference cleanup) instead of parallelizing them, despite both being independently "ready": #843's exact target lines sit inside the code #842 was rewriting, so parallel worktrees would have produced a guaranteed content collision at merge time regardless of file-level disjointness.
- For the new scoped-file-tools feature: chose 8 separate new `fs_*` tools over retrofitting scope-checks and batch support onto the 7 legacy tools (view/glob/grep/ls/write/edit/multiedit) — retrofitting would require changing their `Params` shapes, which the CLI/web/cliprovider-MCP paths all depend on unchanged; new tools cost nothing for existing unscoped callers.
- `FolderScope` matcher deliberately does NOT hook `permission.Request`: a per-item scope denial inside a batch call must not end the whole turn (`StopTurn`), unlike an operator's interactive "no" — these are different severities in the existing tool error-contract, and conflating them would make one out-of-scope item in a 20-item batch kill the other 19.
- T7 done directly (not via `/wrush`) as a deliberate deviation from the plan's stated per-task strategy: genuinely 3-line mechanical edit with zero isolation benefit: — used judgment as orchestrator rather than following the written strategy field rigidly.
- Did not push any of this session's commits without being asked; the review-round-4 arc's `git ls-remote`/actual push happened only after the user's explicit "пуш и наладь ci, если сломается" for that specific arc — the scoped-file-tools commits (T1–T7 so far) have NOT been pushed and no push has been requested for them yet.
