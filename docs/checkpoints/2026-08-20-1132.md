## Decisions

- **#614 and #610 were sent back rather than patched by me.** Both defects
  were mine to find, but the fix belongs with the author — hand-fixing
  model output teaches the loop nothing, and both needed a test I would
  otherwise have had to invent from outside the change.
- **The overload reply replaces backpressure in #612, deliberately.**
  Blocking the reader to slow a client down also silences the one command
  that could rescue it. Refusal at the boundary is the point, not a
  compromise.
- **An expired lease still counts as outstanding (#610).** Treating expiry
  as "gone" would make exit-code correctness depend on winning a race
  against `CleanupExpiredLeases`, which just relocates the defect into the
  expiry window.
- **`DrainNoWork`'s doc was corrected to match the code, not the reverse.**
  Four sites return it non-nil and no consumer relied on the promise;
  changing the contract would have touched code that is currently right.
- **The `dispatch` test's hang was fixed as part of #612 rather than
  filed.** A regression that presents as a 10-minute package timeout is a
  stuck CI job, not a red test — the same shape that already cost this
  series ten minutes a run.
