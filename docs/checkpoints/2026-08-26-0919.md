## Decisions

- Implementing #765-#771 directly (no sub-agents) rather than via another `/babygoal`+`@sl` round, since the user's "изучи ревью, давай исправим" instruction this window did not mention `@sl` — per CLAUDE.md's standing rule against invoking sub-agents without explicit request.
- For #765's regression test, needed an ACTUAL blocking test seam (`cacheKeepAliveFireSeam`, fires-then-blocks-until-signaled, mirroring `mailbox.go`'s `testDrainSeam` idiom) rather than a fire-and-forget one — the first version was vacuous (passed even against deliberately-reverted code) because a non-blocking seam let the production goroutine's own scheduling race ahead of the test's cancel call before it could land.
- For #765/#766, proved non-vacuousness by checking "did Stream actually RETURN promptly" (via the `cacheKeepAliveInFlight` map entry clearing, which only happens in `fireCacheKeepAlive`'s deferred cleanup after the call returns) rather than "was Stream entered" (`lm.calls.Load()>=1`, which is true instantly regardless of whether the call is hung) — the latter signal is too weak and produces false-negative-proof (a test that passes for the wrong reason).
- `cacheKeepAliveInFlight` cancellation is deliberately NOT covered by `cacheKeepAliveMu` (a plain take-and-cancel, safe because double-cancel/cancel-of-done-context is a no-op in Go) — only the `cacheKeepAlive` pending-entry map's check-and-act sequences need the generation-guard-level mutex protection.
- `likelyTTLExpiryThreshold` in `internal/cmd/sessions_cache.go` is a LOCAL constant (5 min), not a cross-package reference to `internal/agent`'s unexported `cacheProfiles` — `internal/cmd` is a diagnostic reader, not a policy owner, so duplicating the real-world constant was preferred over adding a new exported cross-package API surface for one read.
- `providerCacheSupport`'s new `knownCacheReporter` list includes `openai.Name` and `cliprovider.ProviderID` ("local-cli") even though neither needs any of `cacheProfile`'s OTHER facets (explicit markers, inclusive-input correction, keep-alive) — confirmed no import-cycle risk (`internal/agent` already imports `internal/agent/cliprovider` elsewhere).
