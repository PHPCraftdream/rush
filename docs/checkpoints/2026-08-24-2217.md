- Shutdown-button feature (#714) design: reuse the app's existing graceful-shutdown code path exactly (no parallel teardown mechanism, no `os.Exit` from the WS handler) — the handler only signals a channel that the same goroutine already watching `ctx.Done()` (SIGINT) also selects on.
