Check a delegated sub-agent's status without waiting for its own completion notice: running, awaiting_answer (awaits an answer — the legacy between-turns question stop, or a batch child parked inside a live ask_question of a CURRENT batch incarnation, in which case held_question carries the fenced identity (node_id, token, depth, sequence) to answer via inject_agent — see agent's resume_session_id), idle, or a terminal outcome (finished, failed, cancelled, timed_out). Read-only; does not affect the sub-agent.
Called without child_session_id it lists this session's live sub-agent delegations (child_session_id, tool, status, age, last activity); with exactly one delegation it returns that child's full summary directly.
