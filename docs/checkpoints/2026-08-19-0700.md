  probe, because context files are also discovered from the working directory

Both tasks now carry the full finding so the next attempt starts from
evidence. Neither is closed.

## Decisions

- **Two changes reverted rather than shipped on "it builds".** Same bar
  applied twice. A behavioural change whose test cannot distinguish the fixed
  from the broken code is not defensible in review, and leaving it in the tree
  would misrepresent what is covered.
- **The flake was bounded, not re-run.** The guard tells "bounded" from "hangs
  forever"; 8s and 25s are equivalent for that, but not to a loaded machine.
  Verified the widened test still catches the original bug in 0.02s.
- **The race detector works on this machine** (gcc present, CGO_ENABLED=1),
  contrary to the pre-push hook's note that it needs a toolchain that is not
  guaranteed. It should probably be wired into the hook for the concurrency
  packages at least.
