**Three findings came from running things rather than reading them.** A live
CLI smoke run caught four slot names embedded in strings the compiler does
not read, one of which was a genuine wire mismatch between Go and an
already-renamed web store. Adding one SQL query uncovered a sqlc codegen bug:
a multi-byte character in a `.sql` comment silently truncates the generated
statement, which then fails at Prepare time, i.e. at startup. And measuring
the Playwright suite before and after the rename turned "the e2e suite is
broken" into "37 of these predate you, 3 are yours" — and then into 37, back
to baseline.

**Two changes were written, tested, and thrown away before being written
again properly.** The title-join split was disproved by its own test (a
provider 500 completes normally rather than taking an early return, so the
split would have bounded the rare paths and left the common one alone). The
config-pinning test was vacuous twice — `Config()` returns a shared pointer,
and `ContextPaths` is not a usable probe because context files are also
discovered from the working directory — before `WorkerContextWindowText`
turned out to be a field with no filesystem path feeding it.

## Decisions

- **The slot rename is hard, no alias fallback.** Operator's explicit choice.
  Their own global and workspace configs were migrated with backups, verified
  programmatically to differ only in the two key names.
- **Two unprovable changes were reverted rather than shipped.** A behavioural
  change whose test cannot distinguish fixed from broken is not defensible.
  Both were later redone with a probe that works.
- **A failed commit is not nacked**, and **session admission is exclusive
  rather than a refcount** — one execution per session per pump instance was
  always the intended invariant.
- **`internal/db/sql/` is ASCII-only, enforced by the pre-push hook.** A
  correctness rule, not a style one.
- **The flake was bounded, not re-run green**, and the widened test still
  catches its original bug in 0.02s.
